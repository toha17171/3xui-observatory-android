# Changelog

## 1.3.0
- Один стабильный RemoteViews-макет для компактного и расширенного виджета.
- Исправлено пропадание данных при растягивании, убрано пустое пространство.
- 1–8 outbound по доступной высоте; статусы и задержки в выровненных столбцах.
- Средняя, минимальная, максимальная задержка и количество DOWN.
- Адаптивное появление графика и inbound-трафика.
- Индикатор времени обновления, устаревших данных, дополнительных скрытых строк.
- Регрессионная статическая проверка стабильного виджета в GitHub Actions.

## 1.2.0
- Выбор outbound, история задержек, индивидуальные настройки виджетов.

## 1.1.0
- Компактный и расширенный виджеты, фильтр inbound, графики трафика.

## 1.0.0
- Мониторинг Observatory, профили, Keystore, фоновые обновления.
