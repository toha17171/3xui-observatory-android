# 3x-ui Observatory for Android — v1.1

Нативное Android-приложение и два виджета рабочего стола для [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui). Код Java 17, Android SDK 35, Android 8.0+.

## Виджеты

- **Компактный (2×2)**: выбранный сервер, количество включённых inbound, суммарные счётчики ↓/↑ и время последнего опроса.
- **Расширенный (4×4)**: общий трафик, график истории ↓/↑, выбранные inbound с портами/состоянием, а также количество доступных outbound в Observatory и их средняя задержка.
- **Независимые настройки каждого экземпляра виджета**: шестерёнка → выбрать сервер → отметить конкретные inbound → сохранить.
- Нажатие на виджет открывает приложение; «↻» запрашивает обновление.
- Изменение размеров доступно через лаунчер. Точность обновления зависит от Android JobScheduler.

## Приложение

- Профили нескольких HTTPS-панелей, сохранение Bearer токенов с шифрованием Android Keystore.
- Экран «Обзор»: входящие подключения, трафик каждого и общий график, задержки outbound.
- Экран «Настройки»: серверы, токены, проверка подключения к Observatory, фильтр отображаемых inbound, интервал 15/30/60 мин, тема, уведомления по статусу outbound.
- Локальная история inbound: до 96 успешных снимков на сервер. График показывает **усреднённую скорость изменения счётчиков между опросами**, не мгновенную скорость сети. Первые линии появляются минимум после трёх снимков. Сброс счётчиков трактуется как нулевой прирост.
- Все запросы только на чтение. Данные из `settings.clients` не сохраняются даже при ответе старого API.

## API

- `GET /panel/api/server/xrayObservatory` — доступность и задержки **outbound**.
- `GET /panel/api/inbounds/list/slim` — сведения о **inbound** (id, remark, protocol, port, enable, up, down).
- Если `/list/slim` отсутствует (404), используется `/panel/api/inbounds/list` с немедленным удалением всех клиентских настроек из полученного результата.

В новых 3x-ui используйте Bearer-токен с минимальными необходимыми правами на мониторинг и чтение inbound. Токен `monitor` может оказаться недостаточным для `/inbounds/list` в зависимости от версии панели; в приложении ошибка inbound отображается отдельно, без сокрытия данных Observatory. Не размещайте токены в репозитории.

URL панели: `https://host.example/path/` — с учётом кастомного base path. Недоверенные TLS сертификаты отклоняются. При проблемах с правами проверьте `Settings → Security → API Token` в вашей версии 3x-ui.

## Сборка

**GitHub Actions:** [Android APK](https://github.com/toha17171/3xui-observatory-android/actions/workflows/android.yml) → выберите последнюю зелёную сборку → `xui-observatory-debug-apk`.

**Локально:** Android Studio / Android SDK Platform 35 / JDK 21 / Gradle 8.9, задача `assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Оформление

Визуальный стиль воспроизводит текущие принципы темы 3x-ui (тёмный фон `#1a1b1f`, карточки `#23252b`, синий основной `#1677ff`, светлые подписи), ориентируясь на `frontend/src/styles/page-shell.css` и `frontend/src/pages/index/IndexPage.css` оригинального проекта. CSS/React код 3x-ui не копировался: виджеты написаны на Android RemoteViews, графики рисуются Canvas.

Это независимый, неофициальный клиент. После обновления требуется проверить работу с конкретной версией 3x-ui и лаунчером Android.
