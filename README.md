# 3x-ui Observatory — Android

Нативное Android-приложение с виджетом для мониторинга Xray Observatory в 3x-ui.

Функции: несколько панелей 3x-ui, настройка URL и monitor-токена, наблюдение за outbound, задержки и доступность, виджет рабочего стола, ручное обновление и плановые проверки.

**Сборка APK:** вкладка Actions → Android APK → Run workflow; после завершения загрузить артефакт `xui-observatory-debug-apk`.

Требования: Android 8.0+, HTTPS для доступа к 3x-ui, включённый Xray Observatory и API-токен `monitor`. Исходники без реальных адресов и токенов.
