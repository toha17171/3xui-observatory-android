# 3x-ui Observatory — Android v1.3.0

Нативное приложение с адаптивным виджетом для мониторинга [3x-ui](https://github.com/MHSanaei/3x-ui). Java 17 · Android 8.0+ · Android SDK 35.

## Адаптивный виджет v1.3

**Исправлено:** пустая область на растянутом виджете и исчезновение метрик при изменении размера.

Виджет больше **не заменяет один Android RemoteViews XML на другой** при растягивании. Оба варианта в лаунчере используют один и тот же `widget_dashboard.xml`; меняется только число строк и видимость графика, а все обновления данных происходят внутри стабильного макета.

Показатели автоматически подстраиваются под свободное место:

- Малый размер: заголовок сервера, состояние Observatory, средняя задержка и 1–2 outbound.
- Средний: от 2 до 6 outbound, минимальная и максимальная задержка, количество недоступных узлов и суммарный inbound-трафик.
- Большой: до восьми выбранных outbound с отдельной задержкой и статусом, график задержки / доступности / трафика, сводка inbound, время обновления.
- Строки сохраняют полноценный тег в данных (в интерфейсе повторяющийся суффикс Tailscale может сокращаться).
- Неразмещённые outbound учитываются в итоговом количестве, а внизу показывается «ещё N узл.».
- Отображаются только выбранные outbound и inbound; конфигурация индивидуальна у каждого виджета.
- Кнопки «↻» и «⚙» работают независимо от нажатия на основную карточку.

Высота определяется по размерам, которые передаёт Android-лаунчер. Максимум строк и наличие графика зависят от доступного места. В небольших размерах приоритет отдан читаемости, а не плотности информации.

## Настройки приложения

Несколько HTTPS-панелей, зашифрованные Bearer-токены Android Keystore, фильтры inbound и Observatory, выбор outbound для графика, история задержек, обновление через Android JobScheduler, уведомления о недоступных outbound и тема.

## Метрики

- `/panel/api/server/xrayObservatory` — состояние outbound и задержки.
- `/panel/api/server/xrayObservatoryHistory/:tag/:bucket` — история (если доступна); локальная история используется как запасной вариант.
- `/panel/api/inbounds/list/slim` — счётчики inbound, резервный `/list` для старых версий панели.

История inbound показывает **среднюю скорость между опросами**, не мгновенный сетевой поток. Фоновая частота Android 15/30/60 минут, поэтому графики с точками 30/120/300 секунд берутся с сервера 3x-ui, а не опрашиваются Android каждую минуту.

## Как обновиться

1. Установите новую версию поверх 1.2.0 (при совпадении подписи сохранятся профили и токены).
2. Долгое нажатие на виджет → **Изменить размер**. При каждом изменении Android запрашивает повторный рендер с новой высотой.
3. ⚙ открывает настройки конкретного виджета (сервер, outbound, inbound и график).
4. ↻ обновляет информацию с панели.

Если после обновления лаунчер удерживает старый макет, один раз удалите **только виджет** с рабочего стола и добавьте его снова; данные приложения останутся.
